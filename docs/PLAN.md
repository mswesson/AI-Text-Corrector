# TextCorrect v4.0 — План реализации

> Краткий рабочий план. Архитектура и алгоритмы — в [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Порядок работ (этапы из ТЗ §33)

1. **Нативное приложение** — проект, Menu Bar, главное окно, настройки, разрешения.
2. **LLM и AI-панель** — LLMClient, провайдеры, модели, глобальный хоткей, AI-панель, чат, отмена.
3. **Сценарии и текст** — CRUD сценариев, Action Palette, персональные хоткеи, выделение, редактор, повторные инструкции, Copy / Replace Original.
4. **Скриншоты** — захват экрана/области, мультимодальные запросы.
5. **Базовый STT** — whisper.cpp, встроенная Whisper Base, запись, распознавание, Voice Input.
6. **Push-to-Talk** — удерживаемый хоткей, индикатор, безопасная вставка.
7. **LLM-постобработка** — STT → LLM → вставка.
8. **Менеджер STT-моделей** — каталог, загрузка, SHA-256, установка/удаление, фильтры/сортировка, метрики.
9. **Стабилизация** — тесты, производительность, локализация, релиз `.app`, GitHub.

## Четыре прототипа рисков (из рекомендации ТЗ §35)

Проверяются отдельными спайками до/во время соответствующих этапов:

1. **Accessibility**: получение выделения + сохранение контекста + безопасная замена (TextEdit, Notes, Safari, Chrome, Telegram, VS Code).
2. **Push-to-Talk**: корректное удержание (keyDown/keyUp), пропущенный keyUp, сон.
3. **Whisper Base внутри `.app`**: whisper.cpp + AVAudioEngine, Metal, без Python.
4. **Каталог моделей**: загрузка из Hugging Face + переключение STT-моделей разных движков (whisper.cpp GGML / FluidAudio Core ML).

## Ключевые решения

- **Сборка:** Swift Package Manager (исполняемый таргет + библиотека `TextCorrectCore` без UI) и скрипт `Scripts/build_app.sh` для сборки `.app`. Xcode-проект добавляется позже (xcodegen), когда понадобится подпись/нотаризация.
- **Модульность:** `TextCorrectCore` (модели, стореджи, LLM, Accessibility, Keychain) отделён от UI-таргета `TextCorrect`.
- **Краткость:** минимум абстракций, чистые структуры для логики (тестируемо), `@Observable`-сторы для UI.
- **Локализация и полный UI-полишинг** — этап 9; сейчас строки на русском.
