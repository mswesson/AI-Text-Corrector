# Локальные модели речи

Ни одна модель не поставляется внутри `.app`. Whisper Base, Tiny, Small, Medium, Large v3 Turbo и Parakeet v3 скачиваются из Speech Models. Для первой диктовки нужны установленная модель и разрешение Microphone; LLM не требуется.

## Runtime и источники

- whisper.cpp 1.7.5: официальный XCFramework, SHA-256 архива закреплён в `Package.swift`, лицензия MIT.
- FluidAudio 0.17.7: точная версия и коммит в `Package.resolved`, лицензия Apache-2.0. Неиспользуемый runtime нормализации TTS отключён через package traits.
- Whisper GGML: `ggerganov/whisper.cpp` на Hugging Face, ревизия и SHA-256 каждого файла в `Sources/TextCorrectCore/Resources/SpeechModels.json`. Веса Whisper — MIT.
- Parakeet: `FluidInference/parakeet-tdt-0.6b-v3-coreml`, ревизия и SHA-256 каждого компонента в том же манифесте. Исходная модель — NVIDIA Parakeet TDT 0.6B v3, веса CC-BY-4.0. Источник: https://huggingface.co/FluidInference/parakeet-tdt-0.6b-v3-coreml.

Parakeet включён в каталог после офлайн-проверки закреплённых компонентов `Encoder`, `Preprocessor`, `Decoder`, `JointDecisionv3` и словаря на Apple M4 Pro. Загрузка runtime использует `AsrModels.loadLocal`: скрытых автоматических загрузок нет.

## Установка и хранение

Веса размещаются в `~/Library/Application Support/TextCorrect/Models/<id>-<revision>/`.
Загрузчик проверяет место на диске, размер и SHA-256 файлов, затем атомарно публикует каталог установки.
Отмена и ошибка удаляют staging-каталог; незавершённая модель не появляется среди установленных.
Активную или используемую модель удалить нельзя: сначала завершите диктовку и выберите другую.
После скачивания и установки модель работает без сети.

Запись сохраняется во временный CAF-файл, ограничена десятью минутами и удаляется после распознавания или отмены.
Аудио преобразуется в mono Float32 PCM 16 kHz и читается порциями до 30 секунд. В памяти не накапливается вся длинная запись.
Runtime загружается по требованию, одновременно кешируется одна модель, после двух минут простоя кеш освобождается.

## Обновление каталога

1. Выбрать модель уже поддерживаемого runtime и проверить её лицензию и языки по первичному источнику.
2. Получить конкретный commit SHA репозитория весов; не использовать URL на изменяемую `main`.
3. Добавить все необходимые файлы, точные размеры и SHA-256 в манифест. Для небольших Git-файлов SHA-256 вычисляется по содержимому, а не по Git blob ID.
4. Запустить `swift test --disable-sandbox`, проверить установку и офлайн-инференс новой версии, отмену и переключение моделей.
5. Новую модель другого формата включать только вместе с совместимым адаптером приложения.

## Интеграционный smoke-тест

`SpeechCheck` — утилита разработки; в `.app` не входит и сама не обращается к сети.
Она проверяет файлы по манифесту, отменённый запрос и фрагмент настоящей расшифровки:

```bash
say -v Samantha -o /tmp/textcorrect-test.aiff \
  'The quick brown fox jumps over the lazy dog. This is a local speech recognition test.'
swift run SpeechCheck Sources/TextCorrectCore/Resources/SpeechModels.json \
  whisper-tiny /path/to/installed/model /tmp/textcorrect-test.aiff 'quick brown fox'
```

Для Parakeet используются `parakeet-v3` и его каталог установки. Это проверка работоспособности, а не измерение WER или сравнительный бенчмарк.

## Метрики

Проверенных сопоставимых WER/RTFx пока нет: UI показывает «Нет данных».
Манифест допускает записи с языком, корпусом и его версией, нормализацией, версией модели, runtime/backend,
оборудованием, памятью, длительностью аудио, датой и источником. Чужой английский WER не выдаётся за русский.
Для публикации шкал сначала нужен фиксированный корпус с известной лицензией, единая нормализация и одинаковые условия измерения.
