# Проверки TextCorrect

## Автоматические проверки

```bash
swift test --disable-sandbox
# Дополнительный реальный download/progress/SHA-256 на маленьком закреплённом файле:
TEXTCORRECT_TEST_DOWNLOAD=1 swift test --disable-sandbox
xcodebuild -project TextCorrect.xcodeproj -scheme TextCorrect \
  -configuration Debug CODE_SIGNING_ALLOWED=NO build
bash Scripts/build_app.sh
```

Итоговый прогон: 60 тестов без ошибок, включая сетевую проверку прогресса и SHA-256.
Обычный прогон без переменной окружения пропускает только эту сетевую проверку.

Проверяются сессии, сохранение черновика, отмена и поздние ответы, запросы и ошибки LLM,
формат изображений, безопасная замена, конфликты хоткеев, каталог и SHA-256,
опциональная постобработка, преобразование стерео/частоты аудио, EOF и ограниченные порции длинного файла.

Офлайн-инференс Whisper Tiny и Parakeet v3 проверен на сгенерированном системным `say` английском аудио.
Оба runtime распознали контрольную фразу; проверены отмена до загрузки модели и отмена уже запущенного распознавания.
Тестовая машина: Apple M4 Pro, 24 GiB RAM, macOS 27.0. Сборка использует deployment target macOS 14.0.
Доступа к физической машине с macOS 14 в текущей проверке не было.

В UI пройдены семь шагов онбординга, отмена формы провайдера, пропуск LLM, поиск Base,
фильтр установленных моделей и понятная ошибка диктовки без установленной модели.
Системные разрешения при этом не выдавались. Отдельно проверено повторное открытие установленной `.app`: Settings показывает рабочий интерфейс и каталог из шести скачиваемых моделей.

## Проверка поставки

Архив содержит arm64 `.app`, встроенный нативный whisper.framework, ресурсные bundles,
локализации и лицензии зависимостей. Веса моделей отсутствуют.
Скрипт проверяет локальную ad hoc подпись. Это тестовая сборка без Developer ID и нотариализации Apple.

## Оставшаяся ручная матрица

- Выдать/отозвать Microphone, Accessibility и Screen Recording; повторить действие после изменения разрешения.
- Записать голос с реального микрофона, проверить длинную запись и автоматическую остановку через десять минут.
- Проверить удержание Push-to-Talk, автоповтор, отпускание модификатора до основной клавиши, сон и пробуждение.
- Проверить AX в TextEdit, Notes, Safari, Chrome, Telegram и VS Code; сменить поле/курсор/выделение до вставки, закрыть исходное приложение.
- Проверить захват Retina, несколько мониторов, Escape и исключение окон TextCorrect.
- Выполнить запросы к живым локальной и облачной LLM, включая мультимодальную модель, таймаут и отзыв API-ключа.
- Повторить запуск и оба STT runtime на macOS 14 и на других поколениях Apple Silicon.

До прохождения этой матрицы сборка считается preview, а не подтверждённым стабильным публичным MVP.
