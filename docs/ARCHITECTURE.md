# TextCorrect — архитектура

Требования — [SPEC.md](SPEC.md), статус — [PLAN.md](PLAN.md), проверки — [VALIDATION.md](VALIDATION.md).

Главный приоритет — минимум понятного кода. Разделять ответственность по модулям, использовать стандартные средства Swift/macOS, добавлять слои только для текущей задачи. Не сжимать код в сложные однострочники.

## Модули

- **TextCorrectCore**: модели и JSON-сторы, Keychain, запросы LLM, сессия и отмена, чистая проверка целевого поля, каталог и установка STT, опциональная постобработка, локализация. Без AppKit/SwiftUI.
- **TextCorrectSpeech**: whisper.cpp/Metal, FluidAudio/Core ML, отмена native inference, потоковое чтение и преобразование PCM. Один кешированный runtime, выгрузка после простоя. Без UI и LLM.
- **TextCorrect**: SwiftUI-настройки и онбординг, NSPanel/Menu Bar, Carbon-хоткеи и удержание, Accessibility, ScreenCaptureKit, AVAudioEngine, координатор голоса и индикатор.
- **SpeechCheck**: отдельная утилита разработчика для офлайн-интеграционных проверок runtime. В поставку приложения не входит.

`AppDelegate` связывает общий `AppState`, LLM-клиент, AI-панель и голосовой координатор. `AppState` владеет настройками, сценариями, провайдерами и менеджером моделей.

## Данные

- Chat: системный промпт + история текущей сессии + новый запрос. История записывается только после успешного ответа и остаётся в памяти.
- Transform: первый запрос использует исходное выделение; повторный — актуальный черновик и отдельную инструкцию.
- Скриншоты: PNG в памяти; текст кодируется строкой, изображения — частями `image_url` с data URL. Несовместимая модель отклоняется до отправки.
- Голос в панели: временный CAF → mono PCM 16 kHz порциями до 30 секунд → STT → редактируемое поле запроса. Автоматической отправки нет.
- Push-to-Talk: сохранить AX-контекст → запись до отпускания основной клавиши → STT → опциональная LLM-постобработка → проверяемая вставка. Ошибка постобработки сохраняет исходную расшифровку и требует явного выбора пользователя.
- Веса моделей: только скачивание из закреплённого каталога; SHA-256 и атомарная установка в Application Support. Внутри `.app` весов нет.

## Отмена и безопасность

Сетевой запрос отменяется вместе с задачей; идентификатор поколения исключает позднее применение результата. Для whisper.cpp используется потокобезопасный флаг native abort callback. После отмены модель остаётся зарезервированной до выхода работающего inference.

Перед вставкой проверяются исходный процесс, идентичность AX-элемента, диапазон, выделенный текст и доступное содержимое поля. Автоматическая вставка дополнительно требует, чтобы исходное приложение оставалось активным. Неопределённый контекст означает Copy, синтетический Paste не используется. Защищённые поля не читаются.

Запись ограничена десятью минутами, хранится во временном файле и удаляется после обработки/отмены. Готовые тексты и диалоги не сохраняются на диск. API-ключи находятся в Keychain; JSON содержит только настройки. Облачная передача требует согласия.

## Расширение

`LLMCompleting` позволяет подменять транспорт в тестах. `InteractionCoordinator` отделяет управление сессией от UI, а speech-модуль — STT от вставки и LLM. Новый native runtime добавляется в speech-модуль; новый набор совместимых весов — в каталог. Agent Runtime и Tool Calling не реализованы в MVP.
