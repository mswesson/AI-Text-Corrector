# TextCorrect

Нативная menu bar утилита для macOS 14+ на Apple Silicon: AI-чат поверх приложений, сценарии обработки текста, скриншоты, локальный голосовой ввод и Push-to-Talk. Swift, SwiftUI и AppKit; без сервера и Python runtime.

Реализован код этапов 1–9. Текущая поставка — **preview**: автоматические проверки и офлайн-инференс пройдены, живые системные сценарии перечислены в [VALIDATION.md](docs/VALIDATION.md).

## Установка и первый запуск

Откройте `TextCorrect.app` из ZIP-архива. Приложение работает в Menu Bar и остаётся запущенным после закрытия окна настроек.
Онбординг позволяет выбрать горячие клавиши, разрешения, LLM и модель речи; настройку можно пропустить.

**Моделей речи внутри `.app` нет.** Для диктовки откройте Speech Models, скачайте Whisper Base или другую модель и нажмите «Выбрать».
После установки распознавание работает без интернета. Без модели остальные функции приложения доступны.

Тестовая сборка подписана ad hoc; Developer ID и нотариализации Apple нет. Если macOS блокирует запуск, для собственной сборки используйте Xcode или предусмотренный системой ручной запуск доверенного приложения.

## Возможности

- AI-панель по глобальному хоткею, по умолчанию ⌘⇧Space; выбор провайдера и модели, диалог в памяти, отмена.
- Сценарии Chat/Transform со своим промптом, моделью и хоткеем; поиск, стрелки, Enter и Escape.
- Редактор результата и повторная инструкция по текущему черновику, Copy и отдельная кнопка Replace Original.
- Снимок экрана под курсором или выбор области на любом мониторе, миниатюры, несколько вложений и проверка vision-совместимости модели.
- Микрофон AI-панели: распознанный текст попадает в поле запроса, его можно изменить перед отправкой.
- Push-to-Talk: удержание назначенного сочетания, локальная расшифровка, проверка исходного поля и вставка. В случае отказа — доступный результат с Copy.
- Опциональная LLM-постобработка глобальной диктовки по пользовательскому промпту, с сохранением исходной расшифровки при ошибке.
- Каталог Whisper и Parakeet с проверкой SHA-256, прогрессом и отменой загрузки, языками, поиском и сортировкой. Проверенных сопоставимых WER/RTFx пока нет.
- Русский/английский UI по системному языку; для остальных языков — английский.

## LLM-провайдеры

В AI Providers укажите полный Base URL OpenAI-совместимого API, API-ключ при необходимости и Model ID.
Например, LM Studio: `http://localhost:1234/v1`, Ollama: `http://localhost:11434/v1`.
Список можно получить с сервера или ввести вручную. Для vision-модели включите «Изображения» рядом с её названием.
Перед первой облачной передачей приложение запрашивает согласие. API-ключи хранятся в Keychain.

## Сценарии, выделение и диктовка

В Actions задайте промпт и модель. Выделите текст в исходном редакторе, откройте AI-панель и запустите сценарий.
Повторная инструкция в Transform использует текст редактора, включая ручные правки.
«Новая сессия» удаляет диалог из памяти и предупреждает о ручных изменениях.

Для Push-to-Talk назначьте сочетание с модификатором и обычной клавишей в Shortcuts.
Установите курсор в исходном поле, удерживайте сочетание и отпустите основную клавишу после диктовки.
Запись ограничена десятью минутами. Постобработка настраивается в Voice Input; выключенная постобработка не обращается к LLM.
При ошибке LLM можно явно вставить исходную расшифровку или скопировать её.

Вставка проверяет исходный процесс, AX-элемент, диапазон, текст и доступное содержимое поля.
Изменённый курсор, другое поле, закрытый редактор или недостающие AX-атрибуты означают отказ от вставки.
Синтетический ⌘V и чтение защищённых полей не используются. Сложное форматирование и поддержка всех редакторов не гарантируются.

## Разрешения и данные

- Microphone — запись голоса.
- Accessibility — получение выделения и безопасная вставка.
- Screen Recording — снимки экрана.

Разрешения выдаются по действию пользователя и доступны в General. Без LLM работают локальная диктовка, каталог моделей и настройки.
Записи временные и удаляются после обработки или отмены; тексты, диалоги и изображения не сохраняются в постоянную историю.
Телеметрии, облачной синхронизации, автозапуска и автообновлений нет.

## Сборка и проверки

Нужны Xcode с Swift 6.2+ и Apple Silicon. Версии зависимостей закреплены.

```bash
swift test --disable-sandbox
# Сетевая интеграционная проверка маленького файла каталога:
TEXTCORRECT_TEST_DOWNLOAD=1 swift test --disable-sandbox
swift run TextCorrect
bash Scripts/build_app.sh
```

Скрипт создаёт `build/TextCorrect.app` и `build/TextCorrect-macOS-arm64.zip`, включает runtime, ресурсы и лицензии, проверяет локальную подпись.
Веса не скачиваются при сборке и не входят в архив.
Также можно открыть `TextCorrect.xcodeproj` и собрать схему TextCorrect.
